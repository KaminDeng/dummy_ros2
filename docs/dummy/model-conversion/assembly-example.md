# Dummy-B v2 装配转换示例

本文保留特定 STEP 输入、装配修正和历史验证结果；尺寸、性能和例外不应推广为其他机器人常量。
通用方法见[转换流程](README.md)和[CAD 导入](cad-import.md)。

## 输入身份与运动归属

源 STEP 名为 `Dummy-B-v2.step`，原始字节 SHA-256 为：

```text
7099178daac19d822df14ca0495921032a858feabcb8ffb8678c8b06c68b5682
```

该摘要用于识别输入，不证明文件来源可信、机械安装合格或获得运动授权。
对应[完整装配清单](../../../src/dummy-ros2_description/meshes/full_step_manifest.json)
记录转换分组、米制变换和毫米边界。运行资源从描述包加载，不依赖源 CAD 的下载目录或个人工作区。

旧描述入口为 `src/dummy-ros2_description/urdf/dummy-ros2.xacro`，
六轴名为 Joint1～Joint6，规划末端为 `link6_1_1`。
STEP 顶层包含 J1、J2&J3、J4、J5、J6、BASE，共提取 180 个叶子实例。
按物理固定关系映射到基座及前五个运动连杆，输出法兰保持独立第六轴；
同来源的合并 GLB 不保留同等装配关系，不能直接替代实例树。

## 装配差异与几何处理

| 问题 | 处理及保留边界 |
| --- | --- |
| 简化模型缺少电机、盖板 | 保留全部实例用于视觉，逐零件生成保守碰撞包络 |
| 附加减速器误按轴端定位 | 改用末端支架安装面与孔组中心；孔距差异仍未获机械匹配验证 |
| STEP 颜色变银灰 | 解析 XCAF 实体/面继承，导出 OBJ+MTL，再核对实际显示 |
| 碰撞输入过于复杂 | 导出网格总计约 224 万面，逐零件支撑包络约 11.4 万面；没有同口径加速倍数结论 |
| 存在空三角化面 | 检出 83 个空面，将其保守边界纳入碰撞包络，不能忽略丢面告警 |
| RViz 装配挤在一起 | 姿态发布退出导致动态 TF 缺失，预览需持续发布关节状态，不能据此改运动学 |
| 新电机被相邻豁免漏检 | 建立固定电机碰撞子连杆，逐对审查安装接触及非相邻碰撞 |

记录中的 sRGB 壳体色约为 `[0.9098,0.6784,0.1373]`，减速器主体约为
`[0.627451,0.627451,0.627451]`；浅色盖板与深色电机沿用各自源材质。
这些近似值用于解释恢复结果，不是覆盖所有材质的新统一颜色。

相对于旧简化模型，装配修正包括 J2 安装高度增加 9mm，以及 J4 横向安装偏移修正。
安装轴由 STEP 圆柱面读取并核对；转换记录中的轴线残差属于数值对齐，不能当作实物标定精度。
减速器安装点位于 J5 局部 `[-0.0168,0.0625,0]` m，输出端再外延 28mm。
它替换原减速器，控制映射仍为 50:1，不能误算成 2500:1。
附加件 26mm 孔距与 STEP 可识别的 30mm 间距不同，定位采用孔组中心，未证明螺孔能够实际匹配。

`cad_to_link` 使用[局部变换公式](README.md#连杆局部变换与单位)得到；
网格完成局部化后，不能在 URDF origin 再施加同一变换。
完整 CAD 的根坐标后来统一平移，当前基座原点应按[地面坐标](../ground-origin.md)理解，
不能把原转换清单的局部边界直接当成当前世界坐标。

## 初始只读状态验证

历史独立域 188 中确认了六轴动态 TF 与姿态发布，人工查看确认彩色模型正常。
以下是初始 MoveIt 状态有效性服务记录，不是当前进程查询结果或设备动作收据：

| 姿态 | 当时结果 | 接触与耗时 |
| --- | --- | --- |
| Home | 有效 | 无接触，约 1.8ms |
| 现场干涉姿态 | 无效，记录到缺失几何相关接触 | `link2_1_1` 对 `link5_1_1` 约 0.479mm；对 `step_link5_motor_1` 约 0.713mm；约 2.8ms |
| REST | 无效，后续确认存在包络误报 | `link1_1_1` 对 `step_link2_motor_2` 约 6.90mm；约 1.8ms |

干涉姿态六轴约为 `[71.236,-9.869,164.768,132.662,-100.259,-245.744]`°。
J5 同时低于当时名义下限，因此仅凭“状态无效”不足以证明新增碰撞几何生效；
应核对明确的新增接触对。人工外观确认也不构成机械装配或实物路径资格。

## 后续安装与 REST 修复

2026-10-20 的历史安装记录将资源纳入描述包，并实读实际模型、目标模型和 MoveIt 的描述，
确认加载完整模型；新资源与相关回归记录为 105 项通过。该阶段只读服务拒绝了已记录干涉姿态，
没有完整 STEP 模型的实机运动通过结论，不能用旧简化模型的 102 项替代该记录。

早期 REST 接触不是当前模型应继续失败的要求。
后续定位到旋转底座凹支架 `J1/Dummy-0001` 被整件凸包填实，
在局部 Z=24mm 处裁剪全部三角形并纳入跨面交点，分别重建下部与侧板包络，保留至少 0.3mm 外扩；
12 个紧固件的原包络保留，没有放宽 SRDF、关节界限或地面检查。
REST/Home 双向规划及采样验证见[REST 修复](../rest-planning.md)，
适用部件的额外 5mm 规划保护见[最小间隙](../collision-clearance.md)。
这些结果不能由早期“尚需解释”措辞撤销，也不能推广为连续空间或物理执行保证。
