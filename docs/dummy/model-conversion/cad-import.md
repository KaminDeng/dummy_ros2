# CAD 导入、材质与保守碰撞几何

本文区分 STEP 实例数据、视觉资源、碰撞包络和运行期验证。
总体顺序见[转换流程](README.md)，固定输入与测量见[装配示例](assembly-example.md)。

## STEP/XCAF 实例与颜色

支持 XCAF 的 STEP 读取器可以保留装配结构，例如 Open CASCADE 的 `STEPCAFControl_Reader`。
仅导入合并 Shape 或只有一个网格的 GLB，通常无法恢复零件的关节归属。
应保留零件定义、实例路径、父子关系、各级 Location、世界变换、颜色以及最终运动连杆。
组件实例与被引用定义分别处理；用已知实例的世界包围盒核对变换没有重复应用。

颜色可能位于实例、零件标签、Compound、Solid、Shell 或 Face。
实例可覆盖定义颜色；在形状层级递归继承，子层有颜色时覆盖父层。
只查询 Face 会漏掉整块电机或减速器的 Solid 颜色。

历史导入环境使用 cadquery-ocp 8.0.1.1.0、vtk 9.7.1，以及 cadquery-ocp-proxy、
NumPy、SciPy、trimesh 和 fast-simplification。版本用于理解对应结果，不是未来安装版本要求。
OCP 导入可能依赖 VTK 动态库，宜隔离兼容依赖，避免覆盖系统 ROS Python 的 NumPy。

| OCP 8 环境中的操作 | 接口差异与核对点 |
| --- | --- |
| 标签序列 | 使用 `OCP.collections.Sequence_TDF_Label`，不能假定存在 `TDF_LabelSequence` |
| Shape 转 Face | 该环境为 `TopoDS.Face(shape)`；其他绑定版本可能使用 `Face_s` |
| 包围盒 | 使用 `CornerMin()` / `CornerMax()`；该绑定的 `Bnd_Box.Get()` 曾返回未绑定类型 |
| 三角形节点 | `Poly_Triangle.Get()` 的节点索引从 1 开始 |
| 反向面 | `TopAbs_REVERSED` 时反转三角形顶点顺序 |
| 节点坐标 | 应用 `BRep_Tool.Triangulation` 返回的 Location，并核对实例变换 |

这些是历史绑定接口的观察，不是所有 OCP 版本的统一 API；复用时应查当前安装版本的接口说明。

## OBJ/MTL 与显示单位

STL 不保存 STEP 材质颜色。视觉资源可使用 OBJ+MTL，或经过实际加载器验证的有材质 DAE。
同一连杆可按材质合并网格以减少绘制批次，但仍应保留实例归属记录。
OBJ 通过 `mtllib` 引用随包安装的 MTL，再用 `usemtl` 为三角面选择材质。

以下示例假定 OBJ 顶点仍以毫米保存：

```xml
<visual>
  <origin xyz="0 0 0" rpy="0 0 0"/>
  <geometry>
    <mesh filename="package://dummy-ros2_description/meshes/link-colored.obj"
          scale="0.001 0.001 0.001"/>
  </geometry>
</visual>
```

已转成米的网格不能再次乘 0.001；该示意文件名不表示包中存在同名资源。
不要用统一灰色 URDF material 覆盖网格源材质；还需核对 RViz 的显示覆盖、Alpha 和嵌入材质加载。

Dummy-B 导入记录中的 `Quantity_Color` 为线性 RGB，导出前转成 sRGB 后与源配色对应。
其他导出器可能已经转换，不能重复做 gamma。单通道换算为：

```python
def linear_to_srgb(value):
    return 12.92 * value if value <= 0.0031308 else 1.055 * value ** (1 / 2.4) - 0.055
```

材质名相同不保证颜色相同。记录 RGB、颜色空间及实际显示结果；附加近似件也不能只复制名为 silver 的标签。

## 视觉减面与碰撞包络

视觉网格可按材质组减面，优先保持拓扑和边界，并核对孔口、轴、安装平面、盖板边缘和外轮廓。
历史导入曾对超过 4000 面的材质零件尝试减面；这是选取参数，不是尺寸误差上界。
碰撞几何应保守覆盖源实体，可选逐零件凸包、凸分解或基本体，不直接继承视觉减面结果。

整条连杆一个凸包会填实真实凹槽，逐零件凸包也可能封住孔口。
含细长轴的整机包围盒会把轴周围空气一并填入；可分开主体与轴，或审查固定轴孔的真实安装接触。
不能通过扩大整对连杆的碰撞豁免掩盖包络过大。

对单位方向集合 `d_i`，源点集的支撑值及外包络为：

```text
h_i = max_p(d_i · p)
P = intersection_i {x : d_i · x <= h_i + margin}
```

所有法向需归一化、方向覆盖三维且交集有界；在这些前提下，P 包含全部输入点。
包含离散输入点不自动证明覆盖未采样曲面或丢失的 Face。
历史碰撞包络采用二级 icosphere 的 162 个方向、0.3mm 外扩，目的是给约 0.15mm 的网格离散误差留余量；
这不是任意 CAD 曲面误差的证明，也不是实物安全间隙资格。

出现 `faces have been skipped due to null triangulation` 时，必须统计空三角化 Face。
仅验证已成功三角化的部分会漏掉几何；可将失败面保守边界的角点纳入包络，
再核对边界/实体完整性与原 CAD 覆盖。网格离散误差、简化误差和额外规划间隙应分别记录。

## SRDF 与安装接触例外

AllowedCollisionMatrix 按整对连杆豁免，并不只豁免其中某个孔或贴合面。
旧模型的 `Adjacent` 或 `Never` 规则不能在新增电机、盖板后未经审查直接沿用。
把关键部件拆成固定子连杆可以缩小豁免范围，不增加可动自由度；仍须检查该连杆对上的全部碰撞体。
必要时继续拆分，保留其与其他连杆及地面的检查。

安装轴插孔、壳体贴合面可按真实装配关系分别审查。
删除源文件中的豁免也不能证明运行节点的 ACM 已更新，部署后需核对实际值。
REST 的凹支架误报及修复见[REST 规划](../rest-planning.md)。

## 渲染性能与误差测量

反馈/TF 发布频率、RViz Frame Rate 上限和实际渲染帧率是三件事。
上限已为 30FPS 时继续增加配置数值不能证明提速；应固定窗口、视角、模型数量，比较实际帧交换次数。
Xwayland 缺少 DRI3 时可能使用 llvmpipe，不能因机器有显卡就推断已启用硬件渲染。
图形性能诊断不应连带重启串口或控制进程。

视觉简化可以比较原/新网格全部顶点及三角形中心的双向表面距离，超差材质组回退原件。
该离散采样不是连续表面的严格 Hausdorff 上界。
历史六个视觉 OBJ 从 722241 面降至 553751 面，最大双向采样误差约 0.147mm；
软件渲染下仍受负载和视角影响，不承诺稳定 30FPS。
当时的碰撞、运动学及 ACM 摘要应分别核对，不能把后续坐标或包络修复回写成视觉阶段未发生的事实。
详情见[视觉性能记录](../rviz-performance.md)。

## 规划间隙与验证范围

不穿透也可能太近。历史干涉记录中，未穿透目标的 J6 电机代理到基座仅 0.462mm，
故障前实测模型间距也只有 2.759mm；模型距离不能单独解释电机故障首因。
保护应按关键部件和路径最小间隙定义，不能把失能后下落的地面接触倒推成初始干涉。

当前近端保护采用指定近端/远端接触范围，生成外扩 5.01mm，并在 STL 序列化后验证至少 5mm。
固定方向的支撑半空间交集可包含源凸体与指定半径球的 Minkowski 和，但有限方向会更保守。
机械邻接安装面不能统一扩大；额外 ACM 规则只限定辅助保护体的作用范围，不删除原物理碰撞对。
生成器和范围见[最小间隙](../collision-clearance.md)。

验证依次核对实例变换、几何完整性、包络覆盖、真实状态/路径服务结果及运行资源一致性。
干涉状态被拒绝时，要排除只是关节超限、地面或无关假碰撞导致的无效。
独立 ROS 域仍需确保没有硬件控制节点，不向设备域发布预览 joint_states 或修改设备场景。
几何通过、只读规划通过和物理执行资格分别记录。
