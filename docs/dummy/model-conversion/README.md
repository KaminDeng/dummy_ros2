# STEP 装配转换为 ROS 模型

完整 CAD 转换需要同时保留零件实例、运动归属、材质和安装基准，再分别生成视觉与碰撞资源。
显示正确、几何碰撞检查有效、实物装配正确和设备运动通过是不同结论，不能相互替代。

[CAD 导入与网格处理](cad-import.md)解释具体算法和格式；
[Dummy-B v2 装配示例](assembly-example.md)记录固定来源、安装差异和历史测量边界。
当前包内资源的用途见[模型资源说明](../mesh-reading-guide.md)。

## 输入与坐标基准

记录 STEP 文件名、原始字节 SHA-256、长度单位、装配树、每个实例路径和参考姿态。
同一个零件定义可以有多个实例；重复出现的紧固件不能因名称相同而去重。
同时确认实际使用的 Xacro、SRDF、末端连杆、源码包和安装区，不能按目录名或修改时间猜测运行版本。

原模型的关节名称、轴向、零位与初始姿态是对照来源，不自动证明尺寸或安装关系正确。
CAD 与旧模型不一致时，先记录差异并生成候选，不能静默改动设备运动学或电机零位。
附加件还需记录安装平面、孔组中心、输出方向、增量尺寸，以及是替换旧件还是串联新增一级。
几何安装与控制减速比换算分别核对，替换同减速比零件不能重复乘减速比。

## 从装配到连杆

1. 按“实际固定在哪一节连杆上”分配运动归属。装配名称中的 J6 不代表所有零件都随第六轴转动；
   电机壳体、驱动板和盖板通常跟随安装它们的上游连杆，输出法兰跟随输出关节。
2. 读取各级装配变换，在指定参考姿态转换到连杆局部坐标；父级变换只累乘一次。
   用安装轴、连接面和孔组中心交叉验证，不能只凭包围盒中心或 ICP 得分定位。
3. 按实际安装面定位附加件：先对齐面法向和孔组中心，再确定转角及输出方向。
   轴端、壳体面和原法兰面不是同一基准；同轴不等于安装正确。孔距不匹配应单独记录。
4. 分别生成有材质的视觉网格和保守碰撞包络。视觉抽面不自动保持碰撞覆盖，不能直接替换碰撞输入。
5. 审查 SRDF 的允许碰撞矩阵。新增电机、盖板不能继承旧模型整对相邻连杆的豁免而漏检；
   可用固定子连杆缩小例外范围，但仍须检查它与其他连杆和地面的碰撞。
6. 在独立 ROS 域预览模型，并禁用轨迹执行；确认没有硬件控制节点或其他关节状态发布器混入。
   离线转换和预览不授予 USB 控制、回零、使能或物理运动权限。

## 连杆局部变换与单位

约定 `T_A_B` 将 B 系坐标变换到 A 系。参考关节姿态为 `q_ref` 时：

```text
T_link_mesh = inverse(T_world_link(q_ref)) × T_world_part

[p_link]   [ R  t ] [p_mesh]
[   1  ] = [ 0  1 ] [   1  ]
```

`R` 为无量纲旋转矩阵，`t` 与两侧点坐标必须使用同一长度单位。
源 CAD 常用毫米，ROS 平移常用米；先统一单位再做矩阵乘法。
若网格仍保留毫米数值，在 URDF 使用 `scale="0.001 0.001 0.001"`；
若网格已经转成米，则 scale 为 1。毫米转米只做一次，关节角使用弧度。
变换已烘焙到网格时，不能再通过 URDF origin 重复叠加同一变换。

转换清单中的 `cad_to_link` 与 `local_bounds_mm` 应分别按其字段单位解释；
不能因边界是毫米就把齐次矩阵的米制平移也当成毫米。
当前根坐标的统一平移见[地面坐标](../ground-origin.md)，它不同于更改机械零位。

## 验证记录与生效版本

| 项目 | 应保留的证据 |
| --- | --- |
| 装配完整性 | 每个实例的连杆归属、缺件/丢面检查、关键轴线和安装面残差 |
| 单位与变换 | mm→m 的唯一换算位置；多个关节姿态下的连接面、法兰和轴线 |
| 材质 | STEP 颜色继承链、OBJ/MTL 资源和实际加载显示；记录 RGB 所属颜色空间 |
| 碰撞覆盖 | 包络包含源几何、外扩量、空三角化面处理，以及每项安装接触例外 |
| 功能 | Home、REST、干涉姿态及近接触边界的状态/路径结果、接触对和穿透深度 |
| 性能 | 同一环境下的面数、加载耗时、状态查询耗时和实际渲染帧率 |
| 生效版本 | 运行节点的 robot_description、SRDF、资源 URI 和实际允许碰撞矩阵 |

预览模型挤成一团时，依次检查 `/joint_states`、动态 `/tf`、静态 `/tf_static`、
Fixed Frame 和 TF Prefix。只有 robot_state_publisher 而没有持续关节姿态输入，
不足以形成完整动态关节变换。不要为修复预览而重启设备控制节点。

模型更新后，磁盘文件改变不等于运行中的 MoveIt 已重载内存碰撞结构。
部署时须核对安装资源与所有模型消费者，并重新规划；重启 RViz 本身不会刷新 MoveIt 的碰撞缓存。
机械状态改变前仍须遵守独立授权及受控停止流程，不能将关闭预览或规划器当作设备 Stop/Disable。

完整装配、REST 分区包络和最小规划间隙分别见
[完整模型](../full-step-model.md)、[REST 修复](../rest-planning.md)、
[最小间隙](../collision-clearance.md)。转换成功不表示线缆、未提供附件或制造误差均已覆盖。
