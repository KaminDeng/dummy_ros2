# 地面坐标与完整 CAD 原点

## 坐标与数值怎么读

`base_link` 是地面根系，link局部坐标还会叠加各关节变换。本文平移向量单位为m，CAD边界为mm，
角度用rad；统一平移不是更改电机零位。放圆柱时中心Z是高度一半，和圆柱底面Z不同。
基座的安装接触例外有几何来源，不能类推为运动连杆与地面的通用碰撞豁免。
4386个变换与1.11e-16误差描述该次离线等价验证，不确认当前运行节点已重载新模型。
与 [完整模型](full-step-model.md) 和 [REST细化](rest-planning.md) 一起核对安装资源。

2026-10-20：`base_link` 为用户、MoveIt FK/IK、目标预览和障碍物共同使用的地面坐标系。
X/Y 原点在 J1 旋转轴上；Z=0 与基座真实底面齐平，Z 轴竖直向上。
现有轴方向、机械零位、关节角限制以及连杆之间的安装关系保持不变。

## 尺寸来源与变换

- 完整描述原来的 J1 安装点是 `[-0.019225,-0.000523,0.100684]` m，轴方向 `[0,0,-1]`。
- `meshes/full_step_manifest.json` 的 `groups.base.local_bounds_mm` 给出真实 CAD 底面 Z=4.684 mm；
  包内 `full_step_base-colors.obj` 的顶点最低 Z 同为4.684 mm。
- 因而所有物理几何从旧坐标到新 `base_link` 的统一平移为
  `[+0.019225,+0.000523,-0.004684]` m，不旋转。
- 新坐标中的 J1 安装点为 `[0,0,0.096]` m。

实现只调整基座 visual/collision/inertial origin、J1 origin 和
`clearance_base_link` 的 collision origin。保留连杆名称、固定保护体连接和 SRDF，
无需改变允许碰撞矩阵的连杆名。基座保护体的平移放在 collision origin，
与 `scripts/dummy/build_clearance_guards.py` 从源碰撞体复制 origin 的行为一致。

坐标使用米和弧度；界面用毫米显示时只做单位换算。
以该坐标放置竖直圆柱时，底部 Z=0，中心 Z=高度/2。
当前没有已验证的安装螺纹孔坐标或对应 TF；不能把 J1 轴心称为某个安装孔中心。

## 地面接触和验证

真实安装面由 CAD 确定。既有保守基座碰撞网格的最低 Z 原为4.384000778 mm，
比真实安装面低约0.3 mm；平移后约为-0.3 mm。5 mm 间隙保护体也会低于地面。
这些既有保守包络没有重新切削，地面与基座/基座保护体的安装接触例外应保留。

离线验证包括：

- `test_ground_origin.py` 用网格与转换清单交叉检查真实底面、J1轴心及基座/质心/保护体统一平移。
- 新测试在修复前3项失败，修复后与完整模型、J6减速器和间隙保护回归共12项通过。
- 保存修改前完整描述，独立 FK 比较零位及128个随机姿态；4386个视觉、碰撞、质心世界变换
  均仅相差上述统一平移，最大矩阵元素误差 `1.11e-16`。
- 逐项比较所有 joint：只有 J1 的根平移改变，其他 origin、axis、limit 保持一致。

本次未重启 ROS 或硬件，未发送机械臂命令。运行中的节点仍需要在获准部署时重新加载描述；
源码验证不代表当前运行实例已经采用新坐标。
