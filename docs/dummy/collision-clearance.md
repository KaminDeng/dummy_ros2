# 近端与腕部的最小规划间隙

2026-10-20一次真实测试在490个目标后报告机械干涉，并出现J3遥测故障0x1042。最后目标角度约为[-47.496,18.324,176.762,-87.374,12.443,22.388]°。原模型并未穿透：J6电机包络到固定底座的距离仅0.462mm，前臂到腕部约1.734mm；故障前实测姿态对应间隙2.759mm和2.235mm。原MoveIt检查因此放行。故障后下落才进入地面保护体，不能把该接触倒推成首因。电机汇总码本身不提供驱动板具体首故障分类。

描述包现在增加五个无视觉的固定碰撞保护体：固定底座、旋转底座、前臂及前臂的两个电机。每个保护体覆盖对应的原逐零件碰撞外包络，再向外扩至少5mm；只对远端腕部、腕部电机、J6减速器及输出法兰启用。因此这些近端/远端部件接近5mm即按碰撞处理，IK、随机目标、普通规划、插值检查和回Home统一使用。原有物理碰撞体及机械连接豁免不变，原地面保护仍生效。机械连接处不统一扩大：例如正常Home的相邻腕部电机代理间距只有约0.023mm，统一全局padding会误封正常连接。保护体不计入视觉模型，不改变颜色、轴数、关节位置或50:1映射。

生成工具为 `scripts/dummy/build_clearance_guards.py`，输入已展开URDF和描述包的原碰撞网格。它按连通零件构造162方向外支撑平面，外扩5.01mm（额外0.01mm用于STL浮点序列化），保存后重新检查所有凸面与原顶点支撑间距。当前三个网格的最小值均大于5.00999mm；两个电机盒体各方向尺寸增加10.02mm。清单 `src/dummy-ros2_description/meshes/clearance-guards.json` 绑定原始及生成网格SHA，并记录适用部件。禁止对这些保护体使用自动生成的Never碰撞豁免。

真实MoveIt验证已拦截最后目标和故障前实测姿态，上一安全目标和Home仍有效。生产MoveIt、实际TF和目标TF使用同一份模型。运行期记录和距离分析保存在SDK的 `build_dummy/reports/interference-20261020/`；完整20分钟实机测试仍须独立完成，不能用上述几何检查代替。
