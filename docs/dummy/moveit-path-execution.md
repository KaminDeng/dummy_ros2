# MoveIt 连续轨迹执行

MoveIt 返回带时间、位置、速度的连续轨迹采样，采样点不是工艺停车点。
原面板把绕行路径的每一点转换为独立 MOVE_SPEED，导致反复起步、停车和
到位确认。全路径只要不共线就全部保留的压缩逻辑进一步放大了此问题。

## 实际执行通道

手动规划及自动测试默认使用连续通道。面板生成固定20ms六轴命令序列，
用 MOVE_PATH 一次提交给 Native。Native 一次 Begin，在同一 RUN 内逐控制
周期下发位置，保留原 ACK/序号屏障；仅终点收敛后 Complete、回 Hold。
不通过提前提交下一条独立运动来冒充连续执行。

轨迹文件包含固定格式、点数、周期和 boot/reference/session；SHA256 绑定
实际检查过的全部文件字节。Native 在 Begin 前验证文件、身份、逐点位置、
差分速度/加速度、首末零速、累计行程和时长，并完成所有缓冲区分配。
坏文件、身份变化、越限和分配失败均不得 Begin。取消、失联、跟踪、原
许可/租约/看门狗和停止路径继续生效。无需修改本轮主控固件。

## 动态参数与碰撞

规划请求使用面板速度/加速度相对于部署上限的实际比例，禁止写死10%。
规划器 TOTG 的 `ompl.totg.resample_dt` 固定0.02秒，与 Native 相同。原0.1秒
粗采样在加速/匀速切换处做三次插值，会人为抬高差分加速度，导致整条
路径被不必要地降速。

面板按规划位置与速度做 Hermite 插值，生成最终实际命令序列，再检查
全部速度、加速度和实际插值折线的碰撞；真机缺少完整速度时拒绝执行。
TOTG起点小残速仅在已有0.02rad/s起步范围内归零，首末命令明确静止；
修改后的序列仍需完整复核。保留原地面、5mm间隙、关节范围、反馈新鲜度
及设备收据。速度/加速度改变使旧规划失效，需重新规划。

自动测试若某个连续插值候选碰撞，丢弃其所有在途检查并继续筛选新目标，
直到全局测试到期或用户中断；服务失联、设备异常及Home回程碰撞仍报错。

`execution_polyline` 的逐段几何等价合并保留作兼容及诊断用途，容差仍为
1e-12rad，保留转弯、回头及首末点。它本身不能替代连续通道。

## 2026-10-20 验证

已完成80°幅度随机目标连续20次，并在最终20ms规划配置下再次连续20次，
两轮均正常回Home。另将原281点慢路径的同一起终点往返规划为真实绕行，
连续20次完成，每条路径只有一次 Native 开始及完成。最终绕行路径具有
10～16个几何拐点；不是用直线特例代替绕行。

80°单轴往返的下发速度峰值59.94°/s，轨迹1.64秒，实机含到位确认各约
2.37秒；设定始终60°/s、4rad/s²。转弯及短行程受原加速度约束，不要求
每个瞬间都达到速度上限。证据在 dpsdk 的
`build_dummy/reports/continuous-motion-20261020/`，包括每条实际序列、SHA、
逐条到位、原始遥测和阶段日志。软件测试、实机功能及Raw最终归档资格
分别记录；不把未关闭Raw当作完整资格。

## 已运行面板与本次恢复

安装区与源码同步，新进程加载修复。已经运行的 Python 窗口仍持有旧模块，
需重启窗口；关闭面板会释放电机保持力矩，先放稳或支撑机械臂。重启后
使用本次boot保留的零点恢复，不必重新双限位标定。

本轮退Rest后发现旋转座保守凸包填住了真实凹槽，导致与前臂电机包围盒
误报。原CAD电机/旋转座表面间距约6.5mm，保守电机盒与原CAD旋转座亦无
碰撞；原CAD13个零件均无未网格化面。恢复前对标准固定J2收J3、再回Home
的269个样本检查原地面/其余碰撞，再对J2全段121个姿态核对精确旋转座。
随后通过原Native单owner执行两段已核验低速恢复，未改变零点或全局碰撞
豁免。此凸包误报未在本任务中修改；不能把这份限定姿态恢复证据推广为
任意模型碰撞状态都可直接运动。

## 自动测试“连续轨迹”（2026-10-20）

自动测试新增“连续轨迹”复选框。关闭时仍逐目标确认；开启时先准备至少三条曲线和6秒前瞻，在同一RUN中持续接入后续曲线。首尾仍为零速，内部连接采用五次曲线圆滑过渡，因此随机目标附近不再要求精确停稳。面板速度60°/s、加速度4rad/s²保持；只对连接区寻找满足限制的时间，不对已提交路径整体降速。

每条连接后的实际20ms命令曲线均重新经过原0.5°碰撞检查，包含地面与5mm间隙模型。Native续接还核对boot/reference/session、motion、单调版本、文件SHA、精确前缀和至少200ms提前量；滚动删除已执行前缀，窗口内存不随运行时间增长。未检查、迟到或不匹配的更新不能替换原尾段；前瞻不足时沿已验证的零速尾段安全停车，随后继续搜索。

到期/结束停止补充，排空已提交前瞻后回Home；异常/立即中断沿原Cancel停车，不在故障下强行回Home。连续模式单轮最多57分钟，另留60秒尾段与回程预算；用户明确批准goal3530s、permit3550s、trial3560s、累计行程25000rad的运行预算，速度/加速度/跟踪/限位/停车/30秒租约保持。

协议：`MOVE_CHAIN <deg/s> ACCEL <rad/s²> BUDGET <seconds> <sha256> <file>`启动；`EXTEND_PATH <motion> <version> <origin> <unchanged_through> <sha256> <file>`替换未来尾段。索引均为本RUN的绝对20ms样本索引，文件从origin起；`PATH_UPDATED`为接入确认，`PATH_PROGRESS`报告真实发送相位，拒绝更新时原轨迹保持。

## 绕障效率与连续虚影

J6有多圈工作域，全域随机搜索可能使起终点只差约66°的路径往返约981°。
这类运动即使指令峰值达到60°/s，整体也会显得很慢。规划先把J6采样限制在
起终点之间、两侧各留30°；先快速搜索，再增加局部搜索预算，仍失败才回退
完整工作域。人工目标和Home可继续使用完整工作域，不把搜索窗口当作硬限位。
仅自动随机测试还会舍弃J6额外往返超过120°的低质量候选，继续寻找新目标；
不限制目标本身要求的净转角。TOTG路径圆滑容差从默认0.1rad收紧到0.01rad，
减少圆滑后切入障碍物；最终命令曲线仍完整重检碰撞，禁止放宽碰撞或动力学限制。

连续测试虚影以Native已确认的`PATH_PROGRESS`和当前版本缓冲为依据，每帧
插值播放未来150ms的轨迹，滚动前缀和续接后继续更新。两次进度之间最多外推
150ms，避免失去进度后虚影自行一直运动。虚影仍发布在独立目标topic/TF，
不替代实测反馈、不发运动命令，也不逐帧写日志。

验收分别统计实际20ms命令速度/加速度、原始反馈测速、位置差分测速及持续
巡航窗口；短行程、转弯、加减速不能仅凭某一帧低于速度上限判失败，也不能
仅凭一次峰值接近60°/s判整轮通过。

RUN中的续租回执与轨迹生产并行：仅同身份的Renew等待可放行生产，真实
命令ACK、待发样本和其他管理事务仍阻挡下一样本。续租提交仅在SDK明确
返回发布前Busy/NoMemory时重试，期间继续生产，原30秒租约及5秒清理预留
不延长；成功提交后仍须匹配终态才能更新租约账本。传输错误、队列满和
未知失败不重发；退出日志记录预算、反馈、SDK结果和本地提交分类。


几何采样采用按需精细回退：普通请求使用`RRTConnectFast`，若时间参数化后的
验证返回无效路径，再改用`RRTConnectPrecise`检查窄碰撞。两者的
`longest_valid_segment_fraction`分别为0.01与0.0005（工作域比例，不是角度），
避免粗检查反复返回同一条错误直连，也避免对所有随机候选全局增加检查成本。

本轮完整20分钟连续运动完成952个随机目标、947次续接、53次续租，命令峰值
59.9973°/s、加速度3.99960rad/s²。4347个巡航窗口均未低于指令90%；1158个
稳定窗口覆盖全部六轴，实测中位58.8441°/s。初始回Home的几何采样问题另行
修复并保留失败记录；修复后原位姿连续20次重新规划通过，最终版本再完成
62个目标、57次续接，并自动回Home。独立目标topic记录2234个不同姿态。
完整原始采集dropped=0；原始到达/本地入队记录不等同SENT或机械资格。
证据位于dpsdk的`build_dummy/reports/continuous-obstacle-speed-20261020/`。
