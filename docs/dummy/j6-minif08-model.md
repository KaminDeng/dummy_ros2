# J6 MINIF08 减速器模型

本页记录早期简化模型。2026-10-20已按完整STEP模型的末端支架安装面重新定位，
当前真机界面入口及限制见 [完整STEP模型](full-step-model.md)，不要沿用下文旧安装点。

2026-10-19 根据现场确认补入减速器外形。此次为替换原 50:1 减速器，
不是串联；现有控制换算仍为 50:1。用户确认 RViz 中整体模型正确。

## 安装与几何

- 来源：用户提供的 `MINIF08_approx.stl`，已复制到描述包的 `meshes/`，不依赖下载目录。
- STL 单位按毫米处理，缩放为 0.001；包络为 32×32×28 mm。
- `j6_reducer_mount` 固定连接 `link5_1_1` 与 `j6_reducer_housing`，
  安装位置沿用原 J6 原点 `[-0.018506, 0.077, -0.000106]` m。
- STL 的 +Z 通过绕 X 旋转 −90° 对齐 J5 局部 +Y，即法兰向外方向。
- `Joint6` 的父连杆改为壳体，原输出法兰 `link6_1_1` 沿 +Y 外移 28 mm；
  关节名称、转轴方向、零位、限位及总自由度不变。
- STL 为整件近似外形，固定显示于壳体；原输出法兰随 J6 转动。
  孔和内部传动不作为运动副建模。

## 碰撞与运动学

碰撞体采用安装法兰 32×32×7 mm 的盒体，以及直径 30.5 mm、长度 21 mm
的圆柱，不挖孔；验证所有 STL 顶点均被包络覆盖。此近似模型不代表线缆或
未建模附件的完整包络。

SRDF 只豁免壳体与 J5、输出法兰的安装接触；壳体与其他连杆及地面的
碰撞检查保持开启。输出法兰位置变化后，删除旧的 `link3_1_1` 对
`link6_1_1` 的 Never 豁免；原 J5/输出法兰的 Adjacent 豁免也由新邻接关系替代。

面板 FK、IK、规划、逐点碰撞检查和 RViz 共用 `dummy-ros2.xacro`，
因此都采用新法兰位置。Home 下末端原点为
`[-0.018331, 0.256477, 0.327078]` m。
`dummy_reference_chain.*` 为历史求解器对照样本，保留原始几何证据；
不用于当前面板的规划。此次不修改固件身份、Native 或电机参数。

## 验证与生效

新回归覆盖 28 mm 法兰位移、J6 转动时壳体不动、全部 STL 顶点碰撞覆盖、
碰撞豁免范围；连同历史 FK、面板规划及自动测试相关回归共 102 项通过。
三个面板包构建通过。独立域中的真实 MoveIt 服务确认 Home、Rest 有效，
Home 的 FK→IK→FK 位置误差为 0，并拒绝位于新增减速器主体内的球形障碍物。
验证过程无 USB 控制或实机运动。

已安装到 `install_panel_guide`。运行中的 ROS 节点不会自动重读 URDF，
需重启实机面板及其 MoveIt/RViz 后生效。独立 RViz 预览仅用于核对模型，
不会控制实机。验证原件保存在 DPSDK 的
`build_dummy/reports/j6-reducer-model-20261019/`。
