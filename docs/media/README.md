## 播放与维护

GitHub 页面中的相对 MP4 链接可能进入文件预览或下载页，具体播放行为取决于浏览器。
本地可用系统视频播放器打开对应文件。首页还单独放置 GitHub `user-attachments` 地址；
替换上传视频时，应使用实际上传得到的地址，并保持其独占一行以便页面识别。

演示展示录制时的运行过程。判断当前程序版本、碰撞场景、授权和失能状态，应查看
运行中的反馈及对应验证记录；视频素材本身不包含这些状态的实时确认。

修改媒体时，应同步检查首页封面和两条视频链接，以及本页尺寸、时长、大小和摘要。
MP4/JPEG 使用二进制格式，说明写在本页，原文件不插入文本注释。可在仓库根目录运行：

```bash
sha256sum docs/media/dummy_demo.jpg docs/media/dummy_demo.mp4 docs/media/dummy_demo_github.mp4
```
